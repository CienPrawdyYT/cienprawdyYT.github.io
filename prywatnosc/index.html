Cień Prawdy statystyki

Polityka prywatności / Privacy policy

Obowiązuje od / Effective date: 21.10.2026

Polski

Aplikacja Cień Prawdy statystyki to prywatne narzędzie właściciela kanału YouTube Cień Prawdy. Korzysta z niej wyłącznie właściciel kanału.

Jakie dane. Po zalogowaniu przez Google (OAuth) aplikacja odczytuje tylko dane kanału właściciela: statystyki kanału i filmów z YouTube Analytics API (wyświetlenia, czas oglądania, utrzymanie widzów, źródła ruchu, kraje) oraz dane kanału i listę filmów z YouTube Data API. W przyszłości może też wgrywać i edytować własne filmy właściciela. Nie odczytuje danych innych osób.

Gdzie są dane. Token logowania i pobrane statystyki zostają na komputerze właściciela. Aplikacja nie ma serwera, nie przesyła danych osobom trzecim, nie udostępnia ich, nie sprzedaje i nie używa do reklam.

Zgodność. Korzystanie z danych otrzymanych przez Google API jest zgodne z Google API Services User Data Policy, w tym z wymogami ograniczonego użycia (Limited Use).

Usunięcie i cofnięcie dostępu. Dostęp aplikacji do konta Google można w każdej chwili cofnąć na https://myaccount.google.com/permissions. Pobrane dane usuwa się, kasując pliki aplikacji na komputerze właściciela.

Kontakt. kanał YouTube Cień Prawdy.

English

Cień Prawdy statystyki is a private tool of the owner of the YouTube channel Cień Prawdy. It is used only by the channel owner.

Data accessed. After signing in with Google (OAuth), the app reads only the owner's channel data: channel and video statistics from the YouTube Analytics API (views, watch time, audience retention, traffic sources, countries) and channel details and the video list from the YouTube Data API. In the future it may also upload and edit the owner's own videos. It does not access anyone else's data.

Storage. The sign-in token and downloaded statistics stay on the owner's computer. The app has no server and does not transfer, share or sell data, and does not use it for advertising.

Compliance. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Deletion and revoking access. Access can be revoked at any time at https://myaccount.google.com/permissions. Downloaded data is deleted by removing the app's files from the owner's computer.

Contact. YouTube channel Cień Prawdy.
